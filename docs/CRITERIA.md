# Кадр: соответствие ТЗ

Источник — описание кейса «Сравнительный анализ резюме и вакансий». Максимумы ниже взяты из шкалы организаторов. Это матрица реализации и проверок, а не присвоенные себе баллы: корректность на новых данных и оценку защиты определяет жюри.

## Шесть обязательных результатов

| Результат ТЗ | Где проверить |
| --- | --- |
| Рейтинг всех вакансий одного кандидата и лучшая роль | Кандидаты → карточка → Подходящие вакансии |
| Таблица: требование, подтверждение, статус, комментарий | Карточка → выбранная роль → Таблица требований |
| Полное, частичное, несоответствие, не указано | Отдельный статус каждой строки; сводная группа не подменяет его |
| Сильные стороны относительно вакансии | Обзор выбранной пары, ссылки на требования/фрагменты |
| Пробелы и риски | Обзор/таблица, различие неизвестного и отрицания |
| Рекомендации и вопросы для коммуникации | Вопросы и сообщение; вопросы с ориентиром проверки, черновик без автоматической отправки |

## Что не следует выдавать за доказанный результат

99 тестов не означают99% точности. Четыре учебных резюме не заменяют независимый корпус. Настоящая цитата не гарантирует правильную смысловую оценку. Измеренная экономия HR не заявляется. OCR и промышленная авторизация не реализованы. Подробные границы — [VALIDATION.md](VALIDATION.md).
