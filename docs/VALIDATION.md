# Проверки Кадра

## Итоговый код

99pytestpassed. Проверены извлечение документов, единая формула, четыре статуса, синонимы/отрицания/неизвестность, границы стажа/образования, доли составных требований, валидация модельных доказательств, история/черновики, выбор/архив/обратимое удаление и изоляция браузерных сессий. Число тестов не является метрикой точности модели.

Регрессия публичного голоса: GET/api/portal/speech доступен до создания сессии; приватный workspace и похожие префиксы защищены. Функции речи не должны отключаться из-за статуса401.

## Ограничения

Независимая разметка качества на новых профессиях не проведена. Проверенные первые роли4синтетических резюме — ручные ожидания на учебном наборе, а не универсальная точность. Возможны смысловые ошибки, неполный словарь, неоднозначный порядок текста PDF и ошибки STT. OCR, кадровые интеграции, корпоративные роли/аудит/шифрование архивов, мобильные устройства и Windows аппаратно не проверены/не реализованы. Экономия времени не измерена. Решение о найме принимает HR.
